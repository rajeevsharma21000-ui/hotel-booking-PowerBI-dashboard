# 🏨 Hotel Booking Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project is an end-to-end Power BI dashboard built to analyze hotel booking data. It provides insights into sales performance, customer behavior, booking trends, and hotel rankings.

---

## 🎯 Objectives

* Analyze total bookings, users, and revenue
* Track sales trends over time (YoY, MoM, QoQ)
* Identify top-performing hotels
* Understand customer behavior and ratings
* Analyze discount impact on sales

---

## 📊 Key Dashboards

### 1️⃣ KPI Dashboard

* Total Bookings: 800
* Total Users: 1000
* Repeat Users: 201
* Avg Stay Duration: 5.5 days

---

### 2️⃣ Sales Analysis

* Total Sales: 102M
* Discounted Sales: 94.81M
* Total Discount: 7.46M
* Sales by Room Type & City

---

### 3️⃣ Time Intelligence

* Year-over-Year Growth: 16.09%
* Month-over-Month: -67.89%
* Quarter Analysis included

---

### 4️⃣ Customer Analysis

* Active Users: 537
* City-wise customer distribution
* Repeat vs new users

---

### 5️⃣ Hotel Ranking

* Top performing hotels based on sales
* Dynamic Top N filtering

---
